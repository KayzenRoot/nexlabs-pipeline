# Security | HIGH_ASSURANCE nas fronteiras
Threats: prompt injection, memória envenenada, exfiltração cross-client, ferramentas excessivas, credenciais, dependências maliciosas, replay/TOCTOU, duplicação de efeito, quota/custo, privilege escalation, perda de VPS. Políticas imutáveis e aplicadas fora do LLM; agentes não podem aprovar a si, alterar grants, instruções críticas, orçamento, auditoria ou instalação de skills. ARGUS independente, revisor não executor; HIGH_ASSURANCE exige revisão distinta e humana quando necessária.
- Gateway deny-by-default, autenticação forte, autorização por recurso e escopo em toda leitura/mutação/export/cache/stream; RLS sem owner/BYPASSRLS; storage, logs, sessões, caches, grafo, backups e workspace segregados; sem mount global, Docker socket ou shell no navegador.
- Secrets fora de Git e LLM; não copiar tokens OAuth, não automatizar login, não imprimir segredo. Redação de logs; revogação e kill switch testados.
- Supply chain: pin commit/digest, licença por artefato, SBOM, SCA/SAST, inspeção de scripts, sandbox; nenhuma autoatualização upstream, nenhum candidato externo executado antes de aprovação.
- Aprovação: actor autorizado, action/target/tenant, hash do payload e policy, evidência, custo máximo, nonce/idempotency, validade; alteração invalida; commit externo reconciliado antes de retry; logs auditáveis e sem dados desnecessários.
- LGPD: finalidade, minimização, retenção, exclusão e propagação a derivados/caches/restore; teste com dados sintéticos; verificar contratos e bases legais antes de processamento real. Nenhum acesso por ser CEO.
- Finanças: simulação separada, sem ordens reais/mainnet, credenciais de trading, dados pessoais ou anúncios pagos. Acesso a plataforma requer scopes e política permitida. Grupo Facebook manual autorizado; não contornar API.
Proof obligations: zero vazamento nos testes, zero mudança crítica indevida, zero gasto não autorizado, invariantes de autorização/isolamento e restore, revisão independente e rollback/roll-forward. Falha HIGH/CRITICAL bloqueia avanço.

# Security | HIGH_ASSURANCE boundaries
Threats: prompt injection, poisoned memory, cross-tenant exfiltration, excessive tools, compromised credentials, malicious dependencies, replay/TOCTOU, duplicate effects, costs, privilege escalation and VPS loss. Policies enforced outside the model; immutable critical instructions; no self-approval, self-grant, budget increase or disabling ARGUS. Least privilege; RLS without owner/BYPASSRLS; storage, workspace, sessions, caches, graph, logs and backups scoped. No Docker socket access. Secrets outside Git and logs; no OAuth token copying.
Supply chain: pin versions/digests, license and SBOM, SCA/SAST, sandbox, no unqualified skill execution.
Approvals bind actor, tenant, target, payload/policy hash, max cost, validity and idempotency; changed payload invalidates prior approval. Unknown external effect → reconcile before retry. LGPD retention and deletion propagated to derived data. Only synthetic test data. No trading real, mainnet or paid ads. No private host credentials in public repository. No known HIGH/CRITICAL at release; independent proof obligations and restore.

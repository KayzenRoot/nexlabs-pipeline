# API / Integration Contracts (logical)
Request: request/correlation ID, tenant/company/project, actor from authenticated identity, workflow, action, target, payload hash, policy version, Context Lock, idempotency key, timestamps/expiry and evidence. Response: status, reason, source, observed_at, version, freshness and evidence; N/A, STALE, UNAUTHORIZED, NOT_QUALIFIED distinct. Effect intent → validate → approve → lease/fence → execute → reconcile → evidence. No blind retry. Paperclip, GitHub, Cakto, Meta/Google Ads, social channels, market providers and 9Router require specific capability, authorization and quota verification; no invented endpoints. Groups Facebook manual; ads read-only/test; no spending.

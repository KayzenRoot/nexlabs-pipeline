# Architecture
Oracle ARM64 control plane with Paperclip as operational authority, PostgreSQL separated database/roles, pgvector/FTS and relational knowledge graph, Intelligence Hub, durable queue/ledger only for gaps proven by capability matrix, optional 9Router, existing monitoring. Windows official Codex CLI, builds/tests/media; WSL2/remote runner conditional on qualification. WireGuard private network. GitHub canonical for code, decisions and approved skills. No upstream database writes.
Identity and authorization at gateway: company/tenant/project/actor/workflow/resource/policy; intersection and default deny. No automatic grant by role. Candidate resource caps: 4608 MiB RAM and 40 GiB growth; inventory prevails. Initial 1 global LLM execution, 1 Windows heavy job, 1 VPS light/embedding job, 100 queued global/20 project, 2 children/3 delegation levels, lease 120s/renew 30s, fencing, reconciliation. Routines disabled. Quota 70/20/10 only with reliable telemetry; pause normal at 70%, stop new calls at 90%; unknown blocks automation; no paid fallback. Official Codex direct, no credential proxy.
INT: M0–M5, claims, provenance, temporal validity, ACL before queries/caches/graph; multilingual local embeddings candidate; candidate → evaluation → audit → independent approval → canary → release → rollback.
CC: 35 surfaces (2 native/6 augmented/27 extensions), Obsidian dark lime/magenta. CC-WO-001 qualifies plugin vs private sidecar; no initial fork, no alpha by inference, no duplicate state. The full original documents remain mandatory.

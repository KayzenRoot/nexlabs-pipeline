# NexLabs catalog preservation

This Work Order installs infrastructure only. It does not import, hire, enable
or execute agents.

Preserved immutable catalog:

- 105 agents
- 10 departments
- 92 skill packages
- 1,110 assignments
- 1,071 contextual competencies
- 62 workflows
- 35 UI surfaces

The catalog remains in `sources/` under the existing source-lock. Do not
recreate it manually, do not import it into Paperclip, and do not enable
heartbeats, routines, workflows or external effects. Future ZEUS/department
integration must use the existing Registry and contracts after a separate
authorized Work Order.
